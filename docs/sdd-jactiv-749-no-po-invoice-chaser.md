## 1. API Workflow Overview

Weekday schedule (Mon–Fri 10:00 EET/EEST, `Europe/Bucharest`) triggers `no-po-invoice-chaser-api`. It queries Coupa for invoices dated within the past seven days with status `draft` or `new`, excludes credit notes, flags invoices with no properly linked PO at line level, counts the qualifying set, and posts one Slack Block Kit DM to the AP SME when count > 0. On a clean day it exits successfully with no notification. No Coupa records are written (BR-10).

[DEFAULT] Timezone applied via Orchestrator trigger; assumes `Europe/Bucharest` is a supported zone identifier (OQ-07). [ARCHITECT REVIEW] OQ-06: confirm API Workflow runtime is available on the target tenant.

## 6. Error Handling

No retry (BR-08). Single outer catch; all failures mark the run failed with no Slack notification (BR-09).

| Failure | Detection | Response |
|---|---|---|
| S1: Coupa API error / unparseable response | HTTP error or exception at step 4 | Catch logs; run fails |
| S2: Slack delivery failure | `Javascript_ValidateSlack` throws at step 7d | Catch logs; run fails |
| S3: Network timeout | Exception on any network call | Catch logs; run fails |
| S4: Invalid / expired credential | Exception at step 4 or 7c | Catch logs; run fails |
| S5: Unhandled exception | Any other runtime error | Catch logs full detail; run fails |
| B1: Credit note | `invoice-type === 'Credit Note'` at step 5 | Excluded; logged; processing continues |
| B2: Description-only PO | No line-level PO at step 5 | Counted as qualifying (BR-02) |
| B3: Clean day | `qualifyingCount === 0` at step 7 | No Slack; successful exit (BR-07) |

## 8. Testing Strategy

### Happy Path

| # | State | Expected |
|---|---|---|
| HP-1 | Coupa returns ≥1 invoice(s) with status `draft`/`new`, no line-level PO, no credit notes | `qualifying_count ≥ 1`, `slack_sent: true`, DM received by WLX9BD8FN with correct count and working Coupa URL |
| HP-2 | All returned invoices have a linked PO at line level | `qualifying_count = 0`, `slack_sent: false`, run successful |
| HP-3 | Coupa returns empty array | `qualifying_count = 0`, `slack_sent: false`, clean-day exit |

### Business Exceptions

| # | Condition | Expected |
|---|---|---|
| BE-1 (B1) | Invoice with `invoice-type = 'Credit Note'` present | Excluded from count; exclusion logged; remaining invoices processed |
| BE-2 (B2) | PO number in description field only; no line-level linkage | Counted as qualifying per BR-02 |
| BE-3 (B3) | All invoices excluded or zero returned | `qualifying_count = 0`; no Slack; `status: Successful` |

### System Errors

| # | Condition | Expected |
|---|---|---|
| SE-1 (S1) | Coupa returns HTTP 4xx/5xx or malformed JSON | Run fails; logged; no Slack |
| SE-2 (S2) | Slack `ok: false` | Run fails; logged; no Slack |
| SE-3 (S3) | Network timeout | Run fails; logged |
| SE-4 (S4) | Invalid/expired credential | Run fails; logged |
| SE-5 (S5) | Unhandled exception | Outer catch; run fails; full detail logged |
